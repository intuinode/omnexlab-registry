Use a free subdomain with Vercel

About 5 minutes · works with any Vercel project

This guide shows how to give a Vercel project a free yourname.omnexlab.site address, with HTTPS included. omnexlab.site only provides the DNS name; your site keeps running on Vercel.

Do the Vercel step first. Add the name to your Vercel project before you request it. Until Vercel has the name, anyone else could claim it, so the request is refused.

What you need

  • A project deployed on Vercel.
  • A GitHub account at least 30 days old (one subdomain per account).
  • A name that is free and allowed: 3-32 letters, digits or hyphens. See the rules.

Step by step

  1. Add the domain in Vercel. Open your project, then Settings → Domains, and add yourname.omnexlab.site. Vercel will say the DNS is not configured or shows Invalid Configuration. That is expected for now.
  2. Note your Vercel address. Use your project address, for example myproject.vercel.app. If Vercel shows a CNAME value such as <hash>.vercel-dns-017.com, that works too.
  3. Request the subdomain. On the home page, enter your name and your Vercel address, then press the button. GitHub opens a prefilled form; press Submit new issue.
  4. Wait for the bot. It checks that Vercel has the name, creates the DNS record and replies All set, usually within a minute.
  5. Refresh in Vercel. Back in Settings → Domains, press Refresh. The domain should turn valid within a few minutes.

Cloudflare proxy or direct?

By default your name goes through Cloudflare, which gives instant HTTPS. Vercel then shows a Proxy Detected notice, because it recommends no proxy in front of it. Your site still works. If you prefer to avoid the notice, or want HTTPS to end at Vercel itself, choose Direct to my host as the traffic mode, now or later on the manage page.

Not for sensitive data. Do not use a free shared subdomain for logins, private data or payments. Use your own domain for those.

Troubleshooting

  • "Your host does not have the name attached": add yourname.omnexlab.site in Vercel (step 1), then submit the form again.
  • Vercel still says Invalid Configuration after the bot says Done: wait a few minutes and press Refresh. In Cloudflare mode Vercel may keep showing the proxy notice; that is harmless.
  • Certificate warning in the browser: wait a few minutes. With Direct mode, Vercel issues the certificate after the DNS record exists.
  • Name taken or blocked: some names are reserved or look like big brands. See the full rules.

Questions

Is it really free?

Yes, today. See Plans & sponsors for what may change.

Can I move it to another Vercel project later?

Yes. Add the name to the new project first, then use the manage page if the target address changes.

How do I remove it?

Use the cancel form. Only the owner can cancel, and the record disappears within minutes.
