1. The service

omnexlab.site ("we", "us", "the service") lets people request a free subdomain of omnexlab.site, such as name.omnexlab.site. The service only creates a DNS record that points the name at a web host chosen by you, for example Vercel or GitHub Pages. We do not host, store, copy, monitor or edit any website, file or content. The service is run through a public GitHub repository, and traffic to subdomains passes through Cloudflare.

2. Who can use it

You need a GitHub account in good standing that follows GitHub's terms, and you must be old enough to enter a binding agreement where you live (at least 16 if you are in the European Economic Area or the UK, at least 13 elsewhere). If you use the service for an organisation, you confirm you may bind it. By requesting a subdomain you accept these terms.

3. Your subdomain

  • A subdomain is a revocable permission to use a name, not property. You do not own it and cannot sell, rent or transfer it.
  • One subdomain per GitHub account. We may refuse, reserve or change any name, for example to prevent impersonation.
  • You must keep the name attached to your own host. A name that your host no longer serves is removed automatically, because otherwise someone else could claim it.
  • Only the GitHub account that requested a subdomain can change or cancel it.

Not for sensitive use, and the Cloudflare proxy. Free shared subdomains are for portfolios, demos and side projects. Do not use them for sensitive logins, private data or financial transactions; use your own domain for those.
