Point a free subdomain at your Vercel, Netlify or GitHub Pages site. HTTPS works immediately.

Step 1: fill this in
.omnexlab.site
Vercel: yourproject.vercel.app · Netlify: yoursite.netlify.app · GitHub Pages: username.github.io

Step 2: press the button
Create my subdomain on GitHub GitHub opens a page with your file ready. Press Propose new file, then Create pull request. A bot approves valid requests in about a minute.

Step 3: tell your host about the name

  • Vercel: Project → Settings → Domains → add yourname.omnexlab.site. If Vercel shows a warning, wait a minute and press Refresh.
  • Netlify: Site configuration → Domain management → Add a domain.
  • GitHub Pages: Repository → Settings → Pages → Custom domain.

Visitors get HTTPS straight away, because traffic goes through Cloudflare.

Good to know

  • DNS only: we never host or see your content.
  • One subdomain per GitHub account; accounts must be at least 30 days old.
  • No phishing, malware or impersonation: such names are removed.
