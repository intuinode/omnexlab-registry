How it works

  1. Host your site anywhere (GitHub Pages, Netlify, Vercel, Cloudflare Pages and more).
  2. Fork the repo and add one small file: 
    {
  "owner": { "github": "your-username" },
  "record": { "CNAME": "your-username.github.io" }
}
  3. Open a pull request. Valid requests are merged automatically and go live in minutes.

Good to know

  • DNS only: we never host or see your content.
  • One subdomain per GitHub account; accounts must be at least 30 days old.
  • No phishing, malware or impersonation: such names are removed.
