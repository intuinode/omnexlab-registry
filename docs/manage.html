Change or cancel your subdomain

Both open a short request form on GitHub. You must be signed in to the GitHub account that owns the subdomain.

Change where it points

Moved to a new project or host? Add the name to the new host first, then request the change.

Direct means HTTPS terminates at your own host instead of at Cloudflare. Pick it for anything sensitive.

Cancel your subdomain

This releases the name. The DNS record is removed within a few minutes and your site stops answering on this address. Your site itself is not touched, because we never hosted it.
.omnexlab.site

Cancel my subdomain Cancelling cannot be undone, and the name may be taken by someone else afterwards. Only the owner (the GitHub account that requested it) can cancel.

Good to know

Only the owner

The bot compares the GitHub account on your request with the owner of the name. Others are refused.

Remember your host

After cancelling, you can also remove the custom domain from Vercel or GitHub Pages. Leaving it is harmless.

Lost access?

If you cannot use the owning GitHub account any more, contact us and we will help.
